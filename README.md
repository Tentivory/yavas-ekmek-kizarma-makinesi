# Yavaş Ekmek Kızarma Makinesi

## Bu Nedir?

Bu, insanlığın en büyük problemine çözüm: Ekmeğin çok çabuk kızarması.

Biz burada ekmeği **asla** kızartmıyoruz. Sadece kızarmasını bekliyoruz. Çok uzun süre.

### Özellikler

- 10 dakika süren kızartma işlemi (gerçekte hiçbir şey olmuyor)
- Her saniye "hâlâ beyaz" uyarısı
- Ekmek asla yanmaz çünkü asla kızmaz
- Felsefi derinlik: "Beklemek bir sanattır"

### Kullanım

```bash
python kizar.py
```

Sonra oturup izle. Kahve iç. Hayatını sorgula.
